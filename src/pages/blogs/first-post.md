## Next thing I'd personally build

Not another UI feature.

I'd make your **markdown posts look as polished as the homepage**.

That means styling:

- `h1`, `h2`, `h3`
- paragraphs
- code blocks
- inline code
- images
- tables
- lists
- blockquotes

Once that's done, you can write blog posts without touching the frontend again. Every new post will automatically inherit the same polished look, which is exactly what you want from a long-term portfolio.
